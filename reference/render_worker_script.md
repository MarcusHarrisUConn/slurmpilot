# Generate the Standalone Base-R Cluster Worker Script

Emits a self-contained R script (`worker.R`) that executes one SLURM
array chunk on a compute node with zero dependency on `slurmpilot`
itself. The worker loads `payload.rds` and `chunks.rds`, validates
checkpoint SHA-256 integrity before skipping completed chunks,
initializes independent `L'Ecuyer-CMRG` per-chunk / per-task parallel
RNG streams via base
[`parallel::nextRNGStream()`](https://rdrr.io/r/parallel/RngStream.html)
and
[`parallel::nextRNGSubStream()`](https://rdrr.io/r/parallel/RngStream.html),
writes atomic `.rds` result checkpoints with `.sha256` sidecar digests
and `.json` status telemetry, and propagates non-zero exit codes on task
failure.

## Usage

``` r
render_worker_script(output_path = NULL)
```

## Arguments

- output_path:

  Optional file path to write `worker.R`.

## Value

Character vector of script lines (invisibly if `output_path` is
provided, otherwise visibly).

## See also

[`render_sbatch_script()`](https://marcusharrisphd.com/slurmpilot/reference/render_sbatch_script.md),
[`verify_checkpoint()`](https://marcusharrisphd.com/slurmpilot/reference/verify_checkpoint.md)
